# Classgrid Platform Features List

This document tracks specific **Features** (functionalities) that live *inside* the core Dashboard Modules. These will be used to populate the dedicated Features/Tour pages later.

## 🤖 AI & Automation Features
- **Classgrid AI Study Assistant**: RAG-powered knowledge engine for student queries.
- **AI-Powered Viva Examinations**: Automated verbal testing with real-time analysis.
- **OCR Exam Import**: Import physical question papers into digital format via AI.
- **AI Question Paper Generator**: Generate balanced papers based on difficulty and syllabus.
- **Auto-Grading Engine**: Instant results for MCQ and integer-based examinations.
- **Proctoring & Anti-Cheat**: Snapshot analysis, browser locking, and device binding.

## 📊 Academic & Classroom Features
- **GPS-Anchored Attendance**: Verification of physical presence using Haversine formula.
- **Device-Bound Attendance**: Multi-device login prevention to eliminate proxy marking.
- **Timetable Optimization**: Constraint-based scheduling for faculty and classrooms.
- **Digital ID Card Generation**: Automated generation of scannable student IDs.
- **Interactive Syllabus Tracker**: Real-time progress monitoring for faculty and students.

## 💰 Financial & Ops Features
- **Razorpay Zero-Commission Flow**: Direct-to-bank payment integration.
- **Automated Fee Reminders**: Trigger-based SMS/Email/Push alerts for dues.
- **Offline/Online Reconciliation**: Unified ledger for cash and digital payments.
- **QR-Based Canteen Ordering**: Digital menu and tap-to-pay logistics.
- **Real-time Bus Tracking**: GPS-based transport monitoring for parents.

## 💬 Communication & Engagement
- **Threaded Org Chat**: Secure, departmental group messaging with FCM push.
- **Discussion Forums**: Community-driven Q&A with upvoting and categories.
- **Broadcast System**: Multi-channel announcements (Admin to All).
- **Certificate Storage & Management**: Secure vault for institutional certificates.
- **Analytics Digest**: Periodic performance summaries for trustees and management.

---
*Note: These are granular features, NOT the top-level dashboard modules listed on the pricing page.*
